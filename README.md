# 🚘 Sedan Collection — Minimalist Car Catalog with Shopping Cart

A minimalist, luxury-inspired e-commerce style catalog showcasing 12 sedans
(2 models each) from six brands: Ford, Lexus, BMW, Mercedes-Benz, Volvo, and
Alfa Romeo. Built as a personal, visually distinctive portfolio piece.

## ✨ Features
- Clean, minimalist "luxury showroom" design
- 12 sedan cards (brand, model, year, price) with a custom SVG illustration
- Fully functional shopping cart: add, increase, decrease, and remove items
- Real-time total calculation
- Cart persists between visits using `localStorage`
- Fully responsive layout

## 🖌️ Design note
Instead of using real manufacturer photos (which are copyrighted), this
project uses a custom minimalist SVG car illustration, reused across all
cards. This keeps the whole catalog visually consistent and avoids any
copyright issue, while still looking elegant and intentional.

## 🛠️ Technologies
- HTML5, custom SVG illustration
- CSS3 (Grid, Flexbox, transitions, responsive design)
- JavaScript (cart state management, `localStorage` persistence, dynamic rendering)

## 📚 What I learned
- Building a shopping cart from scratch: add / increment / decrement / remove / clear
- Managing application state as a plain JavaScript object (`{ id: quantity }`)
- Designing a minimalist, brand-consistent UI without a design framework
- Persisting user selections with `localStorage`

## 🚀 How to run it locally
1. Clone this repository
2. Open `index.html` in your browser (no installation or dependencies required)
