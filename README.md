# 🚘 Prestige on Wheels — Minimalist Car Catalog with Shopping Cart

A minimalist, luxury-inspired e-commerce style catalog showcasing 12 sedans
(2 models each) from six **fictional** brands: Corvina, Velmont, Halcyon
Motors, Ravenna Auto, Nordfell, and Astorra.

## 💡 Why fictional brands?
Real manufacturer names, logos, and especially official product photography
are protected by trademark and copyright. To keep this project 100% safe to
publish publicly — and to show some brand/design thinking — I invented six
brands, each with its own name and accent color, instead of using real car
manufacturers.

## ✨ Features
- Clean, minimalist "luxury showroom" design
- 12 sedan cards (brand, model, year, price) with a custom SVG illustration, tinted per brand
- Featured carousel with auto-rotation, arrows, and dot navigation
- Fully functional shopping cart: add, increase, decrease, and remove items
- Real-time total calculation, persisted with `localStorage`
- Footer with tech stack badges and direct contact links (LinkedIn, email, GitHub, WhatsApp)
- Fully responsive layout

## 🖌️ Design note
Every car illustration is original, hand-built SVG artwork — not a real
manufacturer photo. Each fictional brand has its own accent color, giving the
catalog a coherent sense of brand identity without any licensing risk.

## 🛠️ Technologies
- HTML5, custom SVG illustrations
- CSS3 (Grid, Flexbox, transitions, responsive design)
- JavaScript (cart state management, carousel logic, `localStorage` persistence)

## 📚 What I learned
- Building a shopping cart from scratch: add / increment / decrement / remove / clear
- Building a carousel component (auto-rotation, manual navigation, dot indicators)
- Managing application state as a plain JavaScript object
- Thinking through brand identity and copyright-safe design decisions

## 🚀 How to run it locally
1. Clone this repository
2. Open `index.html` in your browser (no installation or dependencies required)
